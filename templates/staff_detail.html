📐How Points Are Calculated
Formula reference for {{ emp.staff_type|title }} role.
{% if emp.staff_type == 'purchaser' %}
Bill Rate = PO Checked ÷ PO Received × 100
CS Fulfilment = CS Received ÷ CS Open × 100
Racking Eff. = Items Racked ÷ Number of Items × 100
Speed = Items ÷ (9 hrs × Days)
Points (100) = BillRate×28 + CS×23 + Racking×18 + Speed÷60×12 + Entry×8 + Pending×5 + Workspace×4 + Sweep×2
{% elif emp.staff_type == 'picker' %}
Pick Accuracy = Picked ÷ (Picked + Missed) × 100
Bill Fulfilment = SB Picked ÷ Bills Received × 100
Pick Speed = Items ÷ (9 hrs × Days)
Packing Eff. = Packing ÷ SB Picked × 100
Workspace = Rack×50% + Table×30% + Sweep×20%
Points (100) = Acc×25 + Fulfilment×20 + Speed÷250×18 + Packing×12 + Workspace×10 + CS×8 + Consistency×7
{% else %}
Check Speed = Items Checked ÷ (9 hrs × Days)
Clearance = SB Checked ÷ (SB Checked + Pending) × 100
Clean Check % = Normal Items ÷ Total Items × 100
Consistency = max(0, 100 − std_dev × 2)
Points (100) = Speed÷80×30 + Clearance×25 + CleanCheck×20 + Consistency×10 + PotEff×8 + Volume×5 + Sweep×2
{% endif %}
Minus Marking = Complaint deductions subtracted from points (capped 30)
Grades: ELITE ≥88 · PROFICIENT ≥72 · SATISFACTORY ≥52 · RE-TRAINING <52
{% endif %}
