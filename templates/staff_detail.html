▸How Points Are Calculated
Formula reference for {{ emp.staff_type|title }} role.
{% if emp.staff_type == 'purchaser' %}
Bill Rate = PO Checked ÷ PO Received × 100
CS Fulfilment = CS Received ÷ CS Open × 100
Racking Eff. = Items Racked ÷ Number of Items × 100
Speed = Items ÷ (9 hrs × Days)
VWCR = (Correct÷Total) × (Actual÷Target) × 100, cap 120%
Efficiency Ratio = min(items/200, bills/50) — staff is Efficient only when both = 1.0
Points (100) = BillRate×25 + CS×20 + Racking×15 + Speed÷60×10 + Entry×8 + VWCR×8 + Pending×5 + EffRatio×4 + Workspace×3 + LogCons×2
{% elif emp.staff_type == 'picker' %}
VWCR = (Picked÷Total) × (Items/hr ÷ 50) × 100, cap 120%
Bill Fulfilment = SB Picked ÷ Bills Received × 100
Pick Speed = Items ÷ (9 hrs × Days)
Cleaner Rate = (Normal×100 + Sweep/Rack×10) ÷ Total Volume
Efficiency Ratio = min(items/200, bills/50) — hits hard level only when both = 1.0
Workspace = Rack×50% + Table×30% + Sweep×20%
Points (100) = VWCR×25 + Fulfilment×18 + Speed÷250×15 + EffRatio×10 + Workspace×10 + CS×8 + Cleaner×7 + LogCons×7
{% else %}
Urgent work = one urgent bill or item counts as {{ a_stats.urgent_weight if a_stats else 1.5 }} normal ones
Weighted items = Normal items + Urgent items × 1.5  ·  Weighted bills = Normal bills + Urgent bills × 1.5
Pending (team) = Day's total bills − bills checked by ALL checkers (normal + urgent). Same number for every checker.
Clearance (team) = Bills checked by all checkers ÷ Day's total bills × 100
Weighted Speed = Weighted items ÷ (9 hrs × Days), scored against the hourly target
VWCR = (Weighted items ÷ Items) × (Weighted items/hr ÷ target) × 100, cap 120%
Efficiency Ratio = min(weighted items/day ÷ 200, weighted bills/day ÷ 50)
Log Consistency = max(0, 100 − std_dev × 2) — rewards steady daily work
Points (100) = Weighted Speed 22 + Team Clearance 22 + VWCR 20 + Cleaner 8 + Efficiency 8 + Consistency 8 + Potential 5 + Workspace 4 + Sweep 3
Rule: normal + urgent bills can never be more than the day's total — for one checker, or the whole team together
{% endif %}
Minus Marking = Complaint deductions subtracted from points (capped 30)
Admin Adjustment = Manual ± override set per employee or per entry
Grades: ELITE ≥88 · PROFICIENT ≥72 · SATISFACTORY ≥52 · RE-TRAINING <52
