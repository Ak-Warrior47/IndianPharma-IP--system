# may need to compile. An exact pin like Pillow==10.1.0 has no wheel for newer
# Pythons, so pip falls back to building from source and the deploy fails with
# "Getting requirements to build wheel did not run successfully". That happens
# silently from the repo's point of view: nothing here changed, but Render moved
# the Python version underneath it.
#
# These ranges install cleanly on Python 3.11, 3.12 and 3.13.
